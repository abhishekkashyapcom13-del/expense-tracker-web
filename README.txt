EXPENSE TRACKER - WEB VERSION

1. Install Python 3.x.
2. Open terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open browser and visit: http://127.0.0.1:5000

Features: income add/edit/delete/history, expense add/edit/delete/search, dashboard, balance, analytics, SQLite database.

For online hosting, this Flask app can be deployed to a Python-compatible hosting service. Keep the database backed up because SQLite is local storage.
